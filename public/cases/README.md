# Скриншоты кейсов

Папка на каждый кейс: `public/cases/<slug>/`, например `public/cases/concerts-kz/`.

| Файл | Где показывается | Размер |
|---|---|---|
| `cover.webp` | карточка кейса и шапка страницы кейса | 2400×1500 (16:10) |
| `screen-1.webp` … `screen-3.webp` | блок «Экраны». Приложения и боты: вертикальные скриншоты телефона. Сайты: `screen-1` широкий скрин страницы, `screen-2` и `screen-3` вертикальные мобильные | телефон 1170×2532, сайт 2400×1500 |
| `before.webp`, `after.webp` | слайдер «до / после» | одинаковые, 2400×1500 |

Форматы: webp, jpg, png или avif. Чего нет: остаётся заглушка. После добавления файлов просто пересоберите сайт.

Slug-и: yurta-bank, concerts-kz, raw-management, pomogaybo, slotly, habit-tracker, game, music-player, movie-player, tv-firmware.
